# unirtos-fota-demos

## Overview

unirtos-fota-demos provides an overall demonstration of FOTA (Firmware Over-The-Air) capabilities on UniRTOS.
This directory focuses on remote upgrade examples, covering typical scenarios from firmware download to upgrade flow integration, so you can quickly understand FOTA capability boundaries and solution selection direction.
