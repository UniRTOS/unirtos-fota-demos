# unirtos-fota-demos

中文 | [English](README.md)

## 概述

`unirtos-fota-demos` 用于展示 UniRTOS 下 FOTA（Firmware Over-The-Air）能力的整体方案。
该目录聚焦远程升级相关示例，覆盖从固件下载到升级流程集成的典型场景，便于快速理解 FOTA 能力边界与选型方向。
